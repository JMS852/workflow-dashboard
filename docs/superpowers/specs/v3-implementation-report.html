删除 electron/agent-manager.ts 524 行

  • Agent 注册模型（ID、类型、显示名、工作目录、CLI 路径）→ 改为 AI 选择面板

删除 electron/session-store.ts ~120 行

整个文件删除。原因：旧 session 管理为 CLI --session-id 持久化服务。

PTY 模式下 session 由终端进程自身维持（node-pty 保持进程存活，CLI 自己记住上下文）。 对话历史改为写入 .multi-ai-workflow/sessions/ 由信差管理。

原因：v1 遗留的 AI API 调用路由和 Python 沙箱组件。v3 改为纯 TypeScript/Electron 架构，Python 组件不再需要。

保留 engine/mqtt_client.py 作为可选项（供 Python 生态的外部系统接入 MQTT）。 其余全部归档到 _archive/。

➕ 新增的文件（6 个）

新增 electron/pty-manager.ts ~200 行

职责：管理所有 PTY 实例——创建、销毁、读写、结论检测。

export class PtyManager {
  // 创建一个 AI 的 PTY 实例
  create(type: 'claude' | 'codex', projectDir: string): PtyInstance

  // 销毁一个 AI 的 PTY
  destroy(instanceId: string): void

  // 向所有 PTY 广播消息
  broadcast(message: string): void

  // 向单个 PTY 发送消息
  send(instanceId: string, message: string): void

  // 获取所有 PTY 的输出缓冲区
  getAllOutputs(): Map<string, string>

  // 监听输出中的结论标记
  onConclusion(instanceId: string, callback: (text: string) => void): void

  // 等待所有活跃 PTY 输出结论（带超时）
  waitForConclusions(timeoutMs: number): Promise<ConclusionResult[]>
}

依赖：node-pty（需 npm install）。核心工作：spawn CLI 进程 → 收集 stdout → 正则检测 ──结论── 标记 → 回调通知。

新增 electron/messenger-brain.ts ~180 行

职责：调用 DeepSeek API，做消息的提取、去重、精简、打包。

export class MessengerBrain {
  constructor(apiKey: string, model?: string)

  // 从多个 AI 的完整输出中提取核心结论
  extractConclusions(outputs: Map<string, string>): Promise<ConclusionResult[]>

  // 去重：合并相似结论，标注重复
  deduplicate(conclusions: ConclusionResult[]): Promise<DeduplicatedResult[]>

  // 构建转发消息（含对比表 + 指令）
  buildForwardMessage(
    conclusions: DeduplicatedResult[],
    round: number,
    task: string
  ): Promise<string>

  // 直接调用 DeepSeek（轻量 prompt）
  private askLLM(systemPrompt: string, userContent: string): Promise<string>
}

依赖：@anthropic-ai/sdk 或直接用 fetch 调 DeepSeek API。 API endpoint: https://api.deepseek.com/v1/chat/completions。

轮次信差 LLM 的任务预估 token
Round 1 结束提取 4 个 AI 的结论 → 去重 → 生成对比表 + 辩论指令~800
Round 2 结束整理辩论 → 去重 → 生成辩论汇总 + 投票指令~600
Round 3 结束汇总投票 → 生成最终决策报告~400
新增 electron/window-manager.ts ~150 行

职责：创建和管理每个 AI 的独立 BrowserWindow。

export class WindowManager {
  // 为一个 AI 创建独立桌面窗口
  createAiWindow(info: AiWindowInfo, ptyInstance: PtyInstance): BrowserWindow

  // 关闭 AI 窗口（默认隐藏而不退出）
  closeAiWindow(windowId: string): void

  // 获取所有 AI 窗口
  getAllWindows(): AiWindowState[]

  // 聚焦某个 AI 窗口
  focusWindow(windowId: string): void

  // 排列所有窗口（平铺/层叠）
  tileWindows(): void
}

每个 AI 窗口加载一个只包含 xterm.js 的极简 HTML 页面。 窗口属性：{ width: 600, height: 500, title: 'Claude #1', ... }。 关闭行为：event.preventDefault() + window.hide()（模仿主窗口的托盘隐藏逻辑）。

新增 electron/mqtt-client.ts ~100 行

职责：MQTT 任务订阅 + 结果发布（可选模块）。

export class MqttClient {
  constructor(brokerUrl?: string)

  // 连接到 MQTT Broker
  connect(brokerUrl: string): Promise<void>

  // 订阅任务主题
  subscribeToTasks(callback: (task: MqttTask) => void): void

  // 发布结果
  publishResult(taskId: string, data: object): void

  // 发布轮次结果
  publishRoundResult(taskId: string, round: number, data: object): void

  // 断开连接
  disconnect(): void
}

依赖：mqtt（需 npm install）。Topics： workflow/tasks/new（订阅）， workflow/results/{taskId}（发布）。 如果用户不配置 MQTT，Dashboard 仍可手动输入任务正常工作。
