# 项目状态：MQTT 任务流可视化交互系统

> 最后更新：2026-07-28 | 模式：standard | 阶段：Stage 2 ✅ MQTT + 任务流可视化

## 项目目标

构建一个独立的 Electron 桌面应用，用 MQTT 协议接收任务流，用可视化面板展示多 AI 并行执行过程，用户可以实时决策和批注。

## 技术栈

- **前端**: Electron 28 + React 18 + TypeScript 5 + Vite 5
- **后端引擎**: Python 3.12（独立 .venv）
- **AI 提供商**: DeepSeek / 通义千问 / 豆包 / 混元
- **通信协议**: MQTT (paho-mqtt 2.1) + stdin/stdout JSON

### 当前数据契约

| 名称 | 格式 | 方向 | 说明 |
|---|---|---|---|
| Electron ↔ Bridge | stdin/stdout JSON | 双向 | 每行一个 JSON，action/event 路由 |
| Bridge → MQTT | paho-mqtt | 外部 | workflow/tasks/# 订阅，workflow/results/ 发布 |
| 文件变更通知 | IPC (contextBridge) | Electron → React | chokidar 实时推送 |
| MQTT 任务流 | JSON over MQTT | 外部 → App | {id, title, description, priority} |
